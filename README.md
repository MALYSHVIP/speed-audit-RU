# speed-audit-RU

Отдельный GitHub-ready набор для RU-нод: LibreSpeed с перебором нескольких серверов, резервный HTTP-пробник и понятная проверка сервера на русском языке.

Главный сценарий запуска:

```bash
curl -fsSL https://raw.githubusercontent.com/MALYSHVIP/speed-audit-RU/main/install.sh | sudo bash
```

После первого запуска установщик:

- ставит только нужные пакеты;
- устанавливает `librespeed-cli`, если его еще нет;
- раскладывает локальную команду `speed-audit-ru`;
- сразу показывает итоговый отчет по серверу;
- после отчета открывает русское меню быстрых действий по номеру.

При повторном запуске установщик ничего не переустанавливает и сразу переходит к проверке, если `librespeed-cli`, `jq`, `curl` и локальный скрипт уже на месте.

## Что показывает отчет

- загрузку процессора и краткую оценку;
- сколько занято оперативной памяти и сколько доступно;
- сколько занято и сколько свободно на диске;
- оценку служебного мусора: кеш `apt`, временные файлы и журналы;
- ping, jitter, потери пакетов там, где метод это умеет;
- скорость загрузки и отдачи;
- итоговую рекомендацию простыми русскими словами;
- меню действий: быстрая очистка, очистка кеша, очистка журналов, очистка временных файлов, повторный сетевой тест и повторная полная проверка.
- автоматический перебор нескольких LibreSpeed-серверов и резервный HTTP-режим, если часть узлов не отвечает.

## Структура

- `install.sh` — установщик под запуск через `curl -fsSL ... | sudo bash`;
- `bin/speed-audit-ru` — основной скрипт проверки;
- `docs/GITHUB.md` — как выложить в GitHub и запускать одной командой.

## Установка с GitHub

```bash
curl -fsSL https://raw.githubusercontent.com/MALYSHVIP/speed-audit-RU/main/install.sh | sudo bash
```

## Локальный запуск из папки

```bash
chmod +x install.sh
sudo bash install.sh
```

## Повторная проверка без установки

Если скрипт уже установлен:

```bash
sudo speed-audit-ru
```

После отчета откроется меню, где можно сразу:

- сделать безопасную быструю очистку;
- почистить только кеш `apt`;
- уменьшить старые журналы;
- удалить старые временные файлы;
- повторить сетевой тест с резервными серверами;
- повторить полную проверку.

## Принудительное обновление локального скрипта

Если нужно заново скачать актуальный скрипт проверки:

```bash
curl -fsSL https://raw.githubusercontent.com/MALYSHVIP/speed-audit-RU/main/install.sh | sudo bash -s -- --force-install
```

## Что ставится на сервер

- `librespeed-cli`
- `jq`
- `curl`
- `ca-certificates`

## Куда ставится

- основной скрипт: `/opt/speed-audit-ru/speed-audit-ru`
- команда запуска: `/usr/local/bin/speed-audit-ru`

## Примечания

- установщик рассчитан на Ubuntu с `apt`;
- если `apt` упирается в проблему с `packagekit.service`, установщик пробует ее обойти автоматически;
- RU-версия по умолчанию использует LibreSpeed и резервный HTTP-режим, а не Ookla;
- если часть LibreSpeed-серверов не отвечает, скрипт сам перебирает следующие;
- `install.sh` подтягивает основной скрипт из `bin/speed-audit-ru`, поэтому обновления лучше публиковать сразу и в `install.sh`, и в `bin/`.
