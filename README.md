# Speed Audit RU

Проверка ресурсов Ubuntu и скорости сети для российских нод. Сетевые методы: LibreSpeed и резервная HTTP-загрузка. Ookla Speedtest не устанавливается и не запускается.

## Установка и обновление

```bash
curl -fsSL https://raw.githubusercontent.com/MALYSHVIP/speed-audit-RU/main/install.sh | sudo bash
```

Повторный запуск этой команды обновляет устаревший скрипт до версии установщика. Если версия актуальна и зависимости установлены, пакеты повторно не устанавливаются. Существующий конфигурационный файл сохраняется. Новая копия проверяется и заменяет старую атомарно; неудачное скачивание не повреждает рабочую версию.

Начальное скачивание требует доступа к `raw.githubusercontent.com`. Код установщика не может устранить внешнюю блокировку этого адреса. Чтобы ограничить ожидание при проблемах доступа:

```bash
curl -fsSL --connect-timeout 10 --max-time 60 --retry 2 https://raw.githubusercontent.com/MALYSHVIP/speed-audit-RU/main/install.sh | sudo bash
```

Повторная проверка установленной утилитой:

```bash
sudo speed-audit-ru
```

Отчет без интерактивного меню:

```bash
sudo env SPEED_AUDIT_SKIP_MENU=1 speed-audit-ru
```

После установки через pipe меню читает управляющий терминал, если он есть. Без терминала выводится только отчет. В меню пустой Enter или `0` завершает работу.

## Как измеряется скорость

- По умолчанию выполняются три успешных замера. Загрузка и отдача выбираются независимо: отчет показывает максимумы и сервер для каждого из них.
- Используется актуальный список LibreSpeed, а не только фиксированные ID. Удаленные ID из старых настроек пропускаются. Если доступен один сервер, замеры повторяются на нем.
- `null`, пустой или некорректный JSON, сообщения об ошибках и нулевые скорости не считаются успешным измерением, даже если клиент завершился с кодом `0`.
- Общий лимит сетевой проверки составляет 180 секунд. Каждый внешний запрос также ограничен по времени. Число полученных замеров указывается явно, включая случай, когда удалось выполнить меньше трех.
- Если полноценный LibreSpeed недоступен, проверяются крупные HTTP-файлы, включая Selectel и WCloud. Повторяются успешные загрузки, выбирается максимальная измеренная скорость.
- HTTP-замер принимается только при коде 200/206 и передаче не менее 5 МиБ. Маленькие файлы, HTML, JSON/XML и HTTP-ошибки отбрасываются. При достижении тайм-аута curl результат допустим только после передачи достаточного объема за минимум три секунды.
- HTTP измеряет только загрузку. Отдача и jitter в таком отчете обозначаются как недоступные. Ping берется из отдельной ICMP-проверки, если она прошла; время ответа HTTP не выдается за ping.
- Скорости JSON клиента LibreSpeed v1.0.13 читаются в Мбит/с без предположений по величине числа.
- Отчет содержит отдельные замеры и причины неудачных проверок. При полном провале сети нулевые значения и положительное общее заключение не выводятся.

Измеренный максимум показывает лучший результат среди доступных серверов и маршрутов во время проверки. Он не гарантирует такую скорость до любого адреса и не заменяет проверку тарифа или загрузки порта у хостера. Несколько полных замеров могут передать значительный объем трафика.

## Настройки

Файл: `/etc/speed-audit-ru/speed-audit-ru.conf`. При прямом запуске значения из этого файла имеют приоритет над одноименными переменными окружения.

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| `SPEED_AUDIT_NET_SAMPLES` | `3` | Число успешных замеров, от 1 до 5 |
| `SPEED_AUDIT_NET_DURATION` | `8` | Длительность загрузки и отдачи одного LibreSpeed-теста, от 3 до 20 секунд каждая |
| `SPEED_AUDIT_NET_TIMEOUT` | `180` | Общий лимит, от 30 до 600 секунд |
| `SPEED_AUDIT_NET_MAX_SERVERS` | `8` | Максимум разных LibreSpeed-серверов, от 1 до 20 |
| `SPEED_AUDIT_LIBRESPEED_SERVER_IDS` | пусто | Необязательные приоритетные ID через запятую; затем добавляются актуальные серверы |
| `SPEED_AUDIT_LIBRESPEED_IP_VERSION` | `4` | IPv4 или IPv6 |
| `SPEED_AUDIT_LIBRESPEED_SERVERS_URL` | список librespeed.org | Совместимый JSON-список серверов |
| `SPEED_AUDIT_HTTP_PROBE_URLS` | встроенный список | Крупные тестовые HTTP-файлы, разделенные пробелами |

Старые значения сетевого режима `auto` и `ookla` не включают Ookla. Старый стандартный список HTTP-файлов версии 1.3.0 автоматически заменяется новым списком в памяти; пользовательский список сохраняется.

Принудительно скачать скрипт заново:

```bash
curl -fsSL https://raw.githubusercontent.com/MALYSHVIP/speed-audit-RU/main/install.sh | sudo bash -s -- --force-install
```

## Системные ресурсы и действия

Отчет показывает загрузку CPU, load average, использование RAM и диска, объем кеша apt, журналов и временных файлов. После отчета доступны действия по очистке, поиск крупных каталогов и повторные проверки. При обычном запуске отчета очистка не выполняется.

Зависимости: `librespeed-cli` v1.0.13, `jq`, `curl`, `ca-certificates`, `coreutils`. Основной скрипт устанавливается в `/opt/speed-audit-ru/speed-audit-ru`, команда запуска - `/usr/local/bin/speed-audit-ru`.

## Проверка изменений

```bash
bash -n install.sh
bash -n bin/speed-audit-ru
python3 -m unittest discover -s tests -v
```

Регрессионные тесты используют локальный HTTP-сервер и подставные ответы LibreSpeed. Они не требуют root и не создают публичный тестовый трафик. Проверяются неудачные ответы, выбор максимумов, HTTP-валидация, общий лимит, обновление старой версии, сохранность рабочего скрипта при сбое и поведение меню.
